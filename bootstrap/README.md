# Начальная сборка VOLT

`volt-linux-x86_64` — статический ELF, собранный из исходников `compiler/*.volt`
компилятором VOLT. Системный загрузчик ELF запускает его без libc, C++, GMP,
Python, ассемблера или линковщика. Рядом с проектом нужна только стандартная
библиотека `vstd/`.

```sh
make compiler           # начальный ELF → ./volt
make verify-bootstrap   # две сборки из исходников, сравнение всех байтов ELF
```

Без `make` можно запустить начальный компилятор напрямую:

```sh
./bootstrap/volt-linux-x86_64 compiler/volt_main.volt -o volt
```

Начальный ELF — доверенная точка входа самосборки. Сравнение двух поколений
проверяет воспроизводимость, но не заменяет доверие к этому файлу. Его контрольную
сумму можно сверить из корня проекта: `sha256sum -c bootstrap/SHA256SUMS`.
