# Перечисления с payload

Вариант `enum` может содержать одно скалярное значение, например `i64` или `string`. В объявлении указывается тип, при конструировании — значение точно этого типа. Вариант без данных по-прежнему пишется без скобок.

```volt
enum Token:
    Number(i64)
    Name(string)
    End

fn show(token: Token):
    match token:
        Token.Number(value): print(value)
        Token.Name(value): print(value)
        Token.End: print("end")

show(Token.Number(42))
show(Token.Name("value"))
show(Token.End)
```

`match` требует привязку для варианта с payload и не допускает её для варианта без данных. Все варианты должны быть покрыты явными ветвями или `_`. Отсутствующий вариант — ошибка компиляции. Привязка получает локальную копию payload.

Если хотя бы один вариант содержит данные, весь `enum` хранится как метка `i64` плюс выровненная область payload. Он передаётся и возвращается только во внутреннем ABI VOLT; `extern`, `native` и `fnptr` не поддерживаются. Указатели, массивы, срезы, структуры и другие размеченные значения не допускаются в качестве payload варианта. Сам такой `enum` можно хранить в локальном слоте или в `Option`/`Result`; приведения к целому и сравнения для него недоступны. У `enum` без payload остаются прежнее представление `i64`, сравнения и приведения.
