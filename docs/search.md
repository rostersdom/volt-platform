# Локальный поиск VOLT

`volt-search` строит собственный индекс в памяти только по файлам, переданным
в аргументах. CLI не обращается в сеть, не индексирует соседние файлы и не
переходит по ссылкам в документах.

## Запуск

Из корня проекта (Linux x86-64):

```sh
demo=$(mktemp -d "${TMPDIR:-/tmp}/volt-search.XXXXXX")
make BINDIR="$demo" search
"$demo/volt-search" 'ёжик' tests/search_body.txt tests/search_title.html > "$demo/results.html"
```

Откройте `"$demo/results.html"` в браузере VOLT, например
`apps/bin/browser "$demo/results.html"`, если браузер уже собран. Для сборки
отдельного бинарника: `make BINDIR="$demo" browser`. Проверка
без окна: `"$demo/browser" --check "$demo/results.html"`.

Можно передать свои абсолютные или относительные пути. Ошибка чтения, разбора
или превышение лимита останавливает CLI: ненулевой код, сообщение в stderr,
без частичной HTML-выдачи. Пустой запрос и отсутствие совпадений — обычная
страница «Ничего не найдено.» с кодом 0.

## Что попадает в выдачу

- `.html` и `.htm` без учёта регистра расширения разбираются парсером VOLT.
  Индексируются заголовок и текст документа, не атрибуты, комментарии,
  скрипты, стили или шаблоны. CSS не вычисляется. Остальные файлы читаются
  как обычный текст. Оба формата требуют UTF-8 без нулевых байтов.
- Слова состоят из русских букв, латиницы ASCII и цифр. Регистр не важен,
  `ё` и `е` различаются; сравнение по целому слову, без морфологии, подстрок
  и исправления опечаток. Слова длиннее 96 байт пропускаются.
- Достаточно совпадения хотя бы одного слова. Выше документы с большим числом
  **разных** слов запроса; затем — с большим числом этих слов в `<title>`;
  при равенстве сохраняется порядок аргументов. Повторы не повышают позицию.
- Выдача показывает начало текста, а не фрагмент вокруг совпадения. Запрос,
  заголовки и фрагменты экранируются. Ссылки — абсолютные локальные пути с
  процентным кодированием для VOLT. Переход открывает исходный файл, а не
  очищенную копию; для исходного `.txt` действует обычный просмотр локальных
  файлов в браузере VOLT, не отдельный режим отображения текста.

Индекс пересобирается при каждом запуске CLI. Лимиты: 64 документа, 256 КиБ
на файл, 16 384 различных слова в индексе, 8 192 узла и 16 384 атрибута на HTML,
2 048 байт на абсолютный путь, 1 024 байта на запрос. Это не веб-поиск и ещё
не часть адресной строки браузера.

## Подключение и тесты

`use browser_search`: `browser_search_new()` создаёт индекс,
`browser_search_add(index, absolute_path, source, is_html)` принимает путь и текст
(VOLT-строки), `browser_search_query(index, query, hits, capacity)` заполняет
массив `BrowserSearchHit` в порядке ранжирования. По одному индексу можно делать
несколько запросов. Для освобождения вызовите `browser_search_free(index)`.

```sh
python3 tests/browser_search.py -v
```

Проверка первой ссылки в демо через штатный загрузчик VOLT:

```sh
./volt tests/fixtures/browser_search_links.volt -o "$demo/check-search-link"
"$demo/check-search-link" "$demo/results.html" "$PWD/tests/search_title.html"
```
