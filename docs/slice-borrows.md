# Лексические заимствования срезов

`data[start..end]` создаёт неизменяемый `[]T`, `mut data[start..end]` —
изменяемый `[]mut T`. Источник изменяемого среза — локальная переменная-массив.
Через срез можно читать и изменять элементы; диапазон `[start, end)` и индексы
проверяются во время выполнения.

```volt
let data = [10, 20, 30]
if true:
    let view: []mut i64 = mut data[1..3]
    view[0] += 1
    defer view[1] = 40
print(data[1], data[2]) # 21 40
```

Правило действует на весь массив: либо несколько `[]T`, либо один `[]mut T`,
даже для непересекающихся или пустых диапазонов. Пока действует `[]T`, владелец
доступен для чтения, но не записи. Пока действует `[]mut T`, нельзя читать,
менять, брать адрес владельца или создавать от него другой срез. Заимствования
действуют до конца блока, включая `defer`. После
очистки блока доступ к владельцу снова разрешён.

Исключение — временный срез прямо в позиции аргумента вызова, например
`try_read(fd, mut data[0..n])`. Если вызываемая функция не возвращает
заимствование (её результат не объявлен как `-> []T from input`), заимствование
источника заканчивается вместе с оператором, содержащим вызов: читать и менять
массив можно уже со следующего оператора. Внутри самого оператора правила не
ослаблены: два `mut`-среза одного массива в одном вызове или чтение массива
рядом с его `mut`-срезом в том же выражении — по-прежнему ошибка. Условие
`if`/`while` и границы `for` — тоже точки отпускания: временный срез там не
мешает телу ветки или цикла работать с массивом. Именованный
срез (`let s = mut data[0..n]`) и срез внутри `defer` живут до конца блока,
как раньше. Это относится и к временному срезу на чтение из `[]mut T`: такой
аргумент замораживает исходный изменяемый срез только до конца оператора.

Из `[]mut T` можно создать дочерний неизменяемый срез диапазона — `buf[0..n]`
без префикса `mut` — например, чтобы передать парсеру только прочитанные байты
буфера без копирования. Пока дочерний срез жив (до конца его блока, включая
`defer`), запись через исходный `[]mut T` и передача его как аргумент `[]mut`
запрещены; чтение через исходный срез разрешено. После выхода дочернего среза
из блока запись через исходный снова разрешена.

```volt
fn handle(buf: []mut u8, n: i64) -> i64:
    let got: []u8 = buf[0..n]  # только чтение, buf заморожен для записи
    return parse(got)          # parse принимает []u8
```

`[]mut T` нельзя копировать, переприсваивать, сохранять в агрегате или возвращать
из функции. Обычная VOLT-функция может принять его на время вызова, но один и тот
же срез нельзя передать ей дважды. Срезы не поддерживаются в `extern`, `native`
или косвенных вызовах `fnptr`. Доступ через заранее полученные raw-указатели
остаётся вне проверки заимствований и требует `unsafe`.

## Возврат неизменяемого среза

Сигнатура `-> []T from input` называет ровно один исходный параметр `input`
типа `[]T`. Каждый `return` должен возвращать этот параметр, его неизменяемый
алиас, поддиапазон или результат другого вызова с тем же исходным параметром.
Локальный массив, другой параметр и значение, полученное через `as`, не подходят.

```volt
fn tail(input: []i64) -> []i64 from input:
    if len(input) == 0: return input
    return input[1..len(input)]

let data = [10, 20, 30]
if true:
    let rest = tail(data[0..3])
    defer print(len(rest), rest[0]) # 2 20
data[0] = 0
```

Поддиапазон проверяется по длине входного среза; пустой диапазон разрешён.
Возвращается только пара «адрес, длина», без копирования элементов. Результат
наследует заимствование указанного аргумента: даже если аргумент — временный
срез, массив нельзя изменить до конца блока вызова, включая `defer`.

Источником `from` может быть и адрес владельца из реестра владеющих типов:
`fn owned_buffer_bytes(buffer: ptr<OwnedBuffer>) -> []u8 from buffer`. Такую
функцию может объявить только домашний модуль владельца; тело собирает срез из
сырого хранилища в `unsafe` (`ptr[start..end]` от raw-указателя — без проверки
границ и без лексического источника, хранить его в `let` нельзя). На стороне
вызова результат заимствует сам слот владельца до конца блока: перенос
владельца, пока жив такой срез, — ошибка компиляции. См.
[`owned-buffer.md`](owned-buffer.md).
