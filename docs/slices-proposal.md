# Предложение: срезы с проверкой времени жизни

Термины и пояснения к типу `[]T` приведены в [справочнике языка](language.md).

> **Историческое предложение.** Действующие правила описаны в
> [документации по срезам](slice-borrows.md). Реализованы лексические `[]mut T`
> и возврат `[]T` от одного явно указанного параметра, но не анализ последнего
> использования и не проверка raw-указателей. Ниже сохранён исходный проект.

## Типы и выражения

Тип `[]T` — составной указатель-срез неизменяемых элементов `T`: адрес первого элемента
и длина в элементах. `[]mut T` — изменяемый срез. Это типы-значения размером
16 байт и выравниванием 8; `len(s)` возвращает длину среза.

```volt
fn sum(values: []i64) -> i64:
    let total = 0
    for i in 0..len(values):
        total += values[i]
    return total

fn clear(values: []mut i64):
    for i in 0..len(values):
        values[i] = 0

fn main():
    let data: [4]i64 = [10, 20, 30, 40]
    let middle: []i64 = data[1..3]
    print(middle[0], middle[1]) # 20 30
```

Оператор `base[start..end]` создаёт диапазон `[start, end)`; текущая реализация
принимает его для локального массива и создаёт только неизменяемый срез. Пропуск границ,
отрицательные индексы и диапазоны с `start > end` не поддерживаются. Обе границы
должны удовлетворять `0 <= start <= end <= len(base)` во время выполнения;
нарушение вызывает `panic`. Индексация среза проверяет `0 <= index < len(s)`.
Для массива длина известна статически, для среза хранится в составном указателе.
`data[a..b]` создаёт неизменяемый срез. `mut data[a..b]` пока диагностируется как
неподдерживаемый. Вызов функции принимает срезы только явно:
автоматического превращения массива в срез в других контекстах нет.

Пустой срез допустим при `start == end`; его адрес может быть адресом элемента
сразу за последним. Срез не владеет памятью, не выделяет память в куче и не продлевает
время жизни источника. Возвращать срез из функции, если он ссылается на локальную
память этой функции, запрещено.

## Целевые правила заимствования и времени жизни

1. Каждый срез привязан к области-владельцу: локальной переменной-массиву или
   другому срезу. Он действителен только пока владелец жив и доступен.
2. Одновременно разрешено любое количество живых `[]T`-заимствований либо ровно
   одно живое `[]mut T`-заимствование одной области памяти; совместное наличие
   запрещено. Перекрывающиеся диапазоны также подчиняются этому правилу.
3. Пока существует `[]T`, запрещены запись в базовую память и создание
   `[]mut T`. Пока существует `[]mut T`, запрещены все прочие заимствования и
   прямой доступ к владельцу, включая чтение.
4. Заимствование заканчивается после последнего статически установленного
    использования среза (время жизни до последнего использования). При неоднозначном потоке контроля
   компилятор должен считать его живым до конца области видимости.
5. Передача среза функции создаёт заимствование на время вызова. Функция не может
   сохранить его в глобальной переменной, структуре или массиве либо вернуть с более долгим временем жизни,
    чем у источника. Срез не может быть полезной нагрузкой `Option`/`Result` до
   отдельного решения о совместимости размещения и проверки времени жизни.
6. Указатели и доступ к памяти через `unsafe` не проверяются анализом
   заимствований; использование `unsafe` может нарушить инварианты срезов.

## Ограничения первой версии

Срезы не поддерживают владение памятью в куче, изменение длины, присваивание с другим
владельцем, пользовательские параметры времени жизни, хранение в структурах,
глобальные срезы, variadic ABI, C ABI или автоматическое преобразование
`Option`/`Result`. ABI составного указателя применяется только к обычным VOLT-функциям;
`extern`/`native` и интерфейс C отвергают срезы. Текущий компилятор пока также запрещает
возврат срезов, хранение в структуре/глобальной переменной, вложенные срезы и
создание среза из другого среза. Присваивание уже объявленному срезу запрещено;
небезопасный доступ к памяти может нарушить инварианты.
