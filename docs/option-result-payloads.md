# Структуры и вложенные значения в `Option` и `Result`

В дополнение к скалярным типам (см. [§5 справочника](language.md)) `Option` и `Result` могут хранить копируемую `struct`, enum с данными или другое значение `Option`/`Result`. Тип payload должен совпадать точно. Аннотация, тип параметра или тип результата передаёт контекст вложенным конструкторам, например `Some(Err(None))`.

```volt
struct FileInfo:
    size: i64
    name: string

struct IoError:
    code: i32
    offset: i64

fn forward(input: Result<FileInfo, IoError>) -> Result<FileInfo, IoError>:
    defer print("cleanup")
    let info = input?
    return Ok(info)

let input: Result<FileInfo, IoError> = Ok(FileInfo(42, "data"))
match forward(input):
    Ok(info): print(info.name, info.size)
    Err(error): print(error.code, error.offset)
```

Аргумент копируется целиком, а привязка в `match` копирует активный payload. На успешном пути `?` копирует payload. На пути ошибки он сохраняет ошибку в формате результата функции до выполнения `defer` и `drop`, даже если типы успеха у входного и возвращаемого значения различаются. Обычный `return` тоже сохраняет снимок до очистки.

Представление скалярной формы не меняется: восьмибайтовая метка и область по размеру и максимальному выравниванию payload всех вариантов, с дополнением до выравнивания всего значения. В обычном вызове VOLT аргумент передаётся неявным указателем, а результат записывается в хранилище вызывающего (`sret`). Сигнатуры `extern`, `native` и `fnptr` не поддерживаются. Сохраняются ограничения на глобальные переменные, поля структур, массивы, срезы и указатели на такие значения. Массивы и срезы по значению внутри payload, move-only типы и неограниченная вложенность не поддерживаются.
